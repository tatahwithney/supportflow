# SupportFlow

SupportFlow is a web-based Support Management System developed as the August Backend Capstone Project at Skye8 Company LTD.

## Description

SupportFlow provides a centralized platform for managing support requests. Customers can submit requests and track their progress, while support agents can manage, respond to, and resolve assigned requests.

## Technology Stack

- Node.js
- Express.js
- EJS
- MongoDB
- Mongoose
- JavaScript
- REST API
- JWT
- bcrypt
- Git/GitHub
- Render

## Project Architecture

The application follows the MVC (Model-View-Controller) pattern.
